# Contributing to Housie

Thank you for contributing to this ASP.NET Web Forms project.

Guidelines:

1. Create a feature branch from the current branch.
2. Keep changes small and focused.
3. Restore NuGet packages and build in Visual Studio before submitting changes.
4. Include a clear commit message describing the purpose of the change.
5. If you update project dependencies, document that change in `README.md`.

Notes:

- This repository targets .NET Framework 4.7.2.
- No open-source license file is included yet; add `LICENSE` if you want to publish under a specific license.
