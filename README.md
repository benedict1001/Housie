# Housie

An ASP.NET Web Forms application targeting .NET Framework 4.7.2.

## Project overview

- Framework: .NET Framework 4.7.2
- Project type: ASP.NET Web Forms
- Main project file: `WebApplication2/houserental.csproj`
- Solution file: `WebApplication2.slnx`

## Setup

1. Open `WebApplication2.slnx` in Visual Studio.
2. Restore NuGet packages via Visual Studio or `nuget restore WebApplication2.slnx`.
3. Build the `WebApplication2` project.
4. Run the site using IIS Express or Visual Studio debugging.
